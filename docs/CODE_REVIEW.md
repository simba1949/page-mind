# Browser Partner 代码审查报告

审查日期：2026-07-28

## 结论

原始版本存在可导致 API 密钥泄露、扩展侧边栏内容注入、权限过宽和请求逻辑异常的问题，不建议直接发布。当前工作副本已修复可在本项目范围内落地的高优先级问题，并完成构建、类型检查、单元测试和生产依赖审计。

## 已修复问题

| 级别 | 问题 | 影响 | 修复 |
| --- | --- | --- | --- |
| 高 | 控制台输出完整 API Key、首尾片段和请求正文 | 任何可读取扩展调试日志的人都可能获得密钥和聊天内容 | 删除全部敏感日志 |
| 高 | 页面标题通过 `innerHTML` 注入消息卡片 | 恶意网页标题可向扩展 UI 注入 HTML，造成界面欺骗或外部资源请求 | 全部改为 `textContent`/DOM 节点创建 |
| 高 | AES 密钥与密文同时保存在 `chrome.storage.local` | 加密无法抵御本地存储读取，安全说明具有误导性 | API Key 改存 `chrome.storage.session`，关闭浏览器即清除；自动清理旧持久化密钥 |
| 高 | 保存设置使用浅拷贝 | 加密时会把调用方内存中的明文 Key 改成密文，后续可能拿密文调用 API | 设置对象改为深一层不可变复制，并简化为会话存储 |
| 高 | `<all_urls>` 常驻主机权限且允许任意 HTTP API | 扩展权限过宽，API Key 可能被发送到不安全端点 | 官方 API 使用固定权限；自定义 HTTPS 域名单独授权；HTTP 仅允许 localhost |
| 中 | 当前用户消息被加入历史后又重复追加 | 每个问题会向模型提交两次，增加费用并影响回答 | 构造请求时排除已入队的当前消息 |
| 中 | 点击“清除上下文”后发送时又自动抓取整页 | 用户明确关闭后页面内容仍可能发给模型 | 记录上下文关闭状态并尊重用户选择 |
| 中 | “新建对话”只清内存、不清当前历史 | 重启侧边栏后旧消息重新出现 | 同步清除当前聊天存储，归档逻辑保留 |
| 中 | 用户与助手消息异步追加存储存在覆盖竞态 | 快速响应时历史可能缺一条消息 | 每次顺序保存完整受限快照 |
| 中 | 网页内容可携带提示注入指令 | 页面文本可能诱导模型忽略用户意图或索取秘密 | 将网页标记为不可信参考数据并加入明确隔离指令；隐藏 URL 查询参数 |
| 中 | 右键菜单在 Service Worker 每次启动时重复创建 | 产生 `duplicate id` 错误，菜单行为不稳定 | 仅在 `runtime.onInstalled` 时创建 |
| 中 | 测试配置和测试文件语法损坏 | 原项目 0 个测试可运行 | 修复 Jest 转换配置与测试代码，新增密钥非持久化测试 |
| 低 | 复制脚本吞掉失败 | 静态资源缺失时构建仍显示成功 | 复制错误继续抛出，使构建正确失败 |
| 低 | 发布目录包含 source map、声明和未使用模块 | 包体冗余并暴露更多源码结构 | 新增生产构建配置，只输出两个实际入口及静态资源 |

## UI/UX 改进

- 品牌从泛化的“AI 助手”升级为“页知（PageMind）”，并新增网页书签与洞察星组合图标。
- 重新设计用户消息：品牌蓝渐变、白色高对比正文、身份状态点和更清晰的上下文标签。
- 支持浅色、深色两种主题，并可通过顶部按钮切换。
- 重做品牌头部、本地会话状态、欢迎区、快捷提示卡、消息输入区和设置面板。
- 新增成功 Toast、结构化错误气泡、输入说明和页面上下文关闭提示。
- 增加键盘焦点态、Escape 关闭设置、ARIA 标签、动态语言属性和“减少动画”支持。
- 修复窄侧边栏布局，并限制超长模型列表和异常本地历史，降低卡顿风险。

## 仍需注意

1. 扩展采用浏览器端直连模型 API 的架构，密钥在当前浏览器会话内仍必须以明文存在于内存中。更高安全等级需要自有后端代理、短期令牌或用户口令派生密钥。
2. 提示注入只能缓解，无法仅靠一段系统提示彻底消除。不要让模型基于网页内容执行高权限操作。
3. `npm audit --omit=dev` 为 0；完整审计仍报告 20 个高危开发依赖告警，来自 Jest 工具链中的 `glob`/`minimatch`/`brace-expansion` 传递依赖，不进入扩展 `dist`。已升级到当前项目可兼容版本，后续应继续跟踪上游修复。
4. `sidepanel.ts` 为兼容无打包器而内联了存储、API 和国际化逻辑，与 `src/utils` 存在重复。后续建议引入轻量打包器并拆分模块。
5. 未使用真实 OpenAI/Anthropic 密钥进行在线测试；“测试连接”会对 Anthropic 发起一个最多 1 token 的真实请求，可能产生极小费用。
