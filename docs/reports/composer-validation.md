## 变更范围

将焦点恢复、自动聚焦条件、原生粘贴目标识别、纯文本插入提取到 `src/sidepanel/composer.ts`。控制器保留事件注册、设置弹窗守卫和附件处理，不引入新的服务层或运行时依赖。新增的 jsdom 环境仅用于测试。

补强已取消事件和富文本编辑区的保护；自动聚焦跳过隐藏文档；快捷键处理跳过输入法组合状态及 Alt 组合键。

审计发现 brace-expansion 和 js-yaml 两个包的高危拒绝服务告警，通过兼容依赖更新修复，未使用 force。默认镜像不提供审计接口，因此使用 npm 官方 registry 完成审计。

## 验证边界与待执行的浏览器验收

DOM 测试使用 jsdom，不能模拟 Chromium 地址栏、侧栏挂载动画、系统剪贴板默认操作或真实鼠标光标定位。本次没有完成真实 Chrome/Edge 扩展端到端验收，也没有把单元测试通过视为这些场景已通过。

1. 重新加载 dist 扩展，打开新标签页与侧栏，点击输入框后 Ctrl+V；文字应进入输入框，地址栏不变。
2. 侧栏保持打开，再开新标签页，重复上述操作；选区替换、连续粘贴和右键粘贴均应正常。
3. 在模型请求缓慢时打开侧栏，输入框应可立即操作；打开设置后，延迟聚焦不能抢走 API Key 输入框焦点。
4. 粘贴图片仍应进入附件流程；粘贴恶意 HTML 应显示为文本，不执行脚本或自动发送消息。

依赖审计为当前数据库的已知漏洞检查，不代表完整渗透测试。
